# 완료 직전 확인사항

> 적용 시점: 기능 개발이 완료되고 실제 배포를 준비하는 마지막 단계  
> 원칙: 이 목록은 지금 진행하지 않고, 완료 직전에 한 번에 점검·처리한다.

## 보안 비밀값

- [ ] `application.properties`에서 DB 비밀번호와 JWT 비밀값 기본값을 제거한다.
- [ ] DB 접속 정보와 JWT 비밀값을 운영 환경변수 또는 Secret 관리 도구로 주입한다.
- [ ] 현재 Git 이력에 포함된 DB 비밀번호와 JWT 비밀값은 노출된 값으로 간주한다.
- [ ] 당시 실제 사용 중인 DB 비밀번호와 JWT 비밀값을 새 값으로 교체한다.
- [ ] GitHub 저장소 공개 여부와 협업자 접근 권한을 최종 확인한다.
