# 인프라 / 배포

## 로컬 VM (개발용 인프라 샌드박스)
- 접속: `ssh -i ~/.ssh/shopping_mall_vm -p 2222 test@127.0.0.1`
- 네트워크: NAT + 포트포워딩 (22→2222, 5432→5432, 8080→8080)
- 서비스: PostgreSQL 16(shopping_mall DB), Jenkins(LTS, Docker CLI 포함)
- 정의 파일: 이 저장소의 `infra/`(docker-compose.yml, `.env.example`, Jenkins Dockerfile)
  — VM 안에도 동일하게 배치해 `docker compose up -d`로 기동. 실제 `.env`(비밀번호 등)는
  VM 로컬에만 두고 git에는 올리지 않음(`.env.example`이 템플릿).
- 새 머신에서 이 VM을 처음부터 다시 만들어야 하면
  → [개발환경-세팅.md](./개발환경-세팅.md) 참고 (VirtualBox+Ubuntu만 있는 상태에서
  전체 재현하는 절차).
